Дз алгебра: Розв'яжіть рівняння

Завдання 1
(1,8 - 0,3y)(2y + 9) = 0
Алгоритм підказки:
  1. Згадай: добуток двох множників дорівнює нулю тоді, коли хоча б один із множників дорівнює нулю. Прирівняй кожну дужку до нуля окремо;
  2. Розв'яжи перше просте рівняння: 1,8 - 0,3y = 0;
  3. Розв'яжи друге просте рівняння: 2y + 9 = 0;
  4. Перевір обчислення та запиши обидва корені через крапку з комою `;`.
Завдання 2
(5y + 4)(1,1y - 3,3) = 0
Алгоритм підказки:
  1. Згадай: добуток дорівнює нулю, якщо один з множників дорівнює нулю. Прирівняй кожну дужку до нуля;
  2. Розв'яжи перше рівняння: 5y + 4 = 0 (пам'ятай про знак при перенесенні);
  3. Розв'яжи друге рівняння: 1,1y - 3,3 = 0;
  4. Запиши обидва отримані корені через крапку з комою `;`.
Завдання 3
\[ \frac{7x}{6} - \frac{5x}{18} = \frac{4}{27} \]
Алгоритм підказки:
  1. Зведи дроби у лівій частині рівняння до спільного знаменника (або помнож обидві частини рівняння на найменше спільне кратне знаменників);
  2. Обчисли різницю іксів у лівій частині;
  3. Знайди x, поділивши число у правій частині на коефіцієнт біля x;
  4. Перевір, чи скорочено отриманий звичайний дріб.
Завдання 4
\[ \frac{5x + 3}{5} = \frac{x - 5}{8} \]
Алгоритм підказки:
  1. Скористайся основною властивістю пропорції (перемнож навхрест: чисельник першого на знаменник другого і навпаки);
  2. Розкрий дужки «фонтанчиком» в обох частинах рівняння;
  3. Перенеси доданки з x вліво, а числа — вправо, змінюючи знаки на протилежні;
  4. Зведи подібні доданки та знайди x.
