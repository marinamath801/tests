Дз Кількість коренів рівняння

📌 Інструкція для учня:

  • У Завданні №1 обери з випадаючого списку правильну кількість коренів для кожного з рівнянь.
  • У Завданні №2 запиши числову відповідь або вкажи кількість коренів (якщо рівняння має особливий випадок).
  • Якщо виникають труднощі — тисни кнопку «💡 Потрібна підказка?».
Завдання №1. Скільки коренів має рівняння?
1) \(3x = -10\)
1) Поділи обидві частини рівняння на коефіцієнт біля \(x\) (на 3).
2) Зверни увагу: ми отримуємо одне конкретне числове значення для \(x\).
2) \(0x = 6\)
1) Подумай: якщо помножити будь-яке число на 0, що ми отримаємо в результаті?
2) Чи існує таке число \(x\), яке при множенні на 0 дасть 6?
3) \(0x = 0\)
1) Підстав замість \(x\) будь-яке число (наприклад, 5, -10, 0) і перевір рівність.
2) Чи буде рівність правильною для будь-якого числового значення?
4) \(5x = 0\)
1) Поділи 0 на 5, щоб знайти значення \(x\).
2) Пам'ятай: 0 є числом, тому \(x = 0\) — це один конкретний корінь.
Завдання №2. Розв'яжи рівняння
\(2(x - 3) = 22 - (2x + 28) + 4x\)
1) Розкрий дужки в обох частинах рівняння (будь уважний зі знаком мінус перед дужками!).
2) Зведи подібні доданки окремо зліва та справа.
3) Перенеси доданки з \(x\) у ліву частину, а числа — у праву.
4) Подивись на отриманий результат вигляду \(0x = ...\) і зроби висновок.
